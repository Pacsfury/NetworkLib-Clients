# NetworkLib-Clients

Official client libraries for the NetworkLib backend.

---

This repository contains client implementations for various programming languages, making it easy to integrate your applications with the NetworkLib backend. 

## Supported Languages

* **Lua** (Examples and library files included)
* _More languages coming soon!_

## Installation & Usage

### Lua
1. Download the client file from the `lua/` directory.
2. Include it in your project.
3. Check the `example.lua` file for an example guide.

## Contributing

Contributions are welcome! If you have implemented a client for a language that is not listed yet, please feel free to open a Pull Request (PR). 

### How to contribute a new client:
1. Fork this repository.
2. Create a folder for your programming language (e.g., `python/`, `javascript/`).
3. Include the client library file and a clear code example.
4. Submit a Pull Request.
